# Pyramid Build Sprite Sheet

An 8-frame 4×2 pixel-art sprite sheet generated with GPT Image 2.5 for the portfolio milestone.

- Frames: foundation, one block, two blocks, three blocks, glowing base, half-built pyramid, near-complete pyramid, complete glowing pyramid.
- Interaction: the portfolio selects the frame from the milestone section's scroll position.
- Palette: charcoal, sandstone orange, cream, and bright cyan.
