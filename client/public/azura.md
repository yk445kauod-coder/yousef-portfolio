# Azura Cafe

**Role:** Independent full-stack product build

Azura Cafe is a mobile-first restaurant web application with QR-based access, realtime ordering and synchronization, social-media embedding, responsive motion, and Cloudflare deployment.

- Live project: https://azura-app.pages.dev
- Technologies: React, Firebase Realtime Database, Cloudflare Pages/R2, Framer Motion
