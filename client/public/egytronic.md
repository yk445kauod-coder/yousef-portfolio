# Egytronic_1.0

**Role:** Fine-tuned language model project

Egytronic_1.0 is an 8B-parameter Llama 3.1-based model tuned for Egyptian Arabic, local culture, and practical inference. The project includes multilingual instruction-data preparation and published F16/GGUF workflows.

- Model card: https://huggingface.co/YousefKhamis/Egytronic_1.0
- Technologies: Transformers, PyTorch, Unsloth, llama.cpp
- Languages: Egyptian Arabic, Modern Standard Arabic, English
