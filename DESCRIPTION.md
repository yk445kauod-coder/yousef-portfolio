# Site Description

Yousef Madbouly is a junior software developer based in Alexandria, Egypt. He builds full-stack web products, applied AI systems, and educational technology. His featured work includes Egytronic_1.0, an 8B-parameter Egyptian Arabic language model; Azura Cafe, a QR-first restaurant web application; and SmartBoard AI, an AI-powered classroom whiteboard.

The portfolio is a single-page, terminal-inspired experience with real project evidence, a pixel-art progression layer, interactive Three.js visuals, optional ambient sound, and direct links to the deployed products and model.
