# SEO, GEO & AI Agent Discovery

## Search Engine Optimization

The site exposes a canonical URL, title, description, robots policy, XML sitemap, Open Graph metadata, Twitter card metadata, a web manifest, semantic sections, one H1 on the homepage, descriptive image alt text, and keyboard-accessible controls.

## Generative Engine Optimization

The page metadata and visible copy identify the person, location, role, specialties, projects, technologies, and canonical project links in plain language. Structured JSON-LD describes Yousef as a Person, the portfolio as a WebSite, and the featured products as a project list so answer engines can cite the correct entity and URLs.

## AI Agent Optimization

Important actions are represented as normal anchors with readable labels, not icon-only controls. Project links are direct and external links are marked with safe `rel` attributes. The site includes a predictable section order: identity, approach, selected work, toolkit, and contact. `robots.txt` explicitly allows crawling of public content.

## Deployment Note

If the site is moved to a custom domain, update the canonical URL, Open Graph URL, sitemap location, and robots sitemap line in one pass.
